- (requirement by sofia) R1 (RPT.FR-1; parent R42): A report needs a reporting period, defaulting to the period selected on the dashboard, and takes an optional activity type that filters the summary, the line items and both exports and is named on the page and in file names; both filters live in the page address, and switching organization resets only the period.
- (requirement by sofia) R2 (RPT.FR-2; parent R41): The summary shows the total, each type with its share (all three without a type filter, 0 when empty) and every month of the period with each type, zero for months without activity, in kg CO2e to 2 decimals, as tables only, matching the dashboard total.
- (requirement by sofia) R3 (RPT.FR-3; parent R43, R25, R31): Read-only line items list the matching activities oldest first with date, type, quantity, unit, the factor used with its version, and emissions in kg CO2e to 2 decimals, paginated with the total count, with the disclaimer on the page.
- (requirement by sofia) R4 (RPT.FR-4; parent R44, R31): The line items CSV holds every matching line item under one header row, UTF-8 with a byte-order mark, dates as YYYY-MM-DD, numbers at full stored precision with a dot and no separators, each row's factor value, version and disclaimer-carrying source label, descriptions starting with = + - or @ prefixed with an apostrophe, and a file name naming organization, period, type filter, content and date; its emissions column sums exactly to the report total, and 50,000 rows export within 10 seconds.
- (requirement by sofia) R5 (RPT.FR-5, Should; parent R45): The summary CSV has one header row, one row per month of the period with a column per type and a total column, a final Total row equal to the report total, a source column carrying the disclaimer on every row, and R4's precision.
- (requirement by sofia) R6 (RPT.FR-6; parent R31): Summary and line items show skeletons while loading; with no matching activity the summary shows zeros and the line items an empty state whose "Add activity" opens M2's add form; with no periods the page leads to adding one; exports are disabled with a reason when there are no line items; a failed load or export shows Retry and never leaves a partial file.
- (requirement by sofia) R7 (RPT.FR-7, Could; parent R33): Line items, the type breakdown and the line items CSV carry the activity type's informational scope label.
- (constraint by sofia) The report calculates nothing: figures come from M3 and line items from M2's records, so it always matches the dashboard (EMI.FR-5, EMI.FR-6).
- (constraint by sofia) CSV numbers keep full stored precision so spreadsheet sums equal the totals; the screen shows 2 decimals (NFR-01).
- (constraint by sofia) The demonstration disclaimer travels with every exported file (FR-EMI-09, Q-10).
- (constraint by sofia) Text written to a CSV is protected against spreadsheet formula injection (NFR-06).
